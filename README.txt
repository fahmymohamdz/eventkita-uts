NIM: 411242036
Nama: Muhammad Fahmi Mauludin

ISI FOLDER
- index.html    : halaman utama dengan 6 informasi kegiatan
- detail.html   : halaman detail kegiatan (konten berubah berdasarkan parameter URL)
- style.css     : seluruh pengaturan tampilan dan responsive layout
- script.js     : data kegiatan dan interaksi menu mobile
- img/          : logo dan ilustrasi lokal berbentuk SVG

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder eventkita_uts.
3. Klik dua kali index.html atau buka folder menggunakan Visual Studio Code.
4. Untuk mencoba halaman detail, klik tombol "Lihat detail" pada salah satu kartu.

CATATAN UNTUK TUGAS
- Seluruh nama kegiatan, tanggal, lokasi, penyelenggara, dan biaya merupakan data contoh.
- Sesuaikan isi website dengan arahan dosen dan hasil wireframe Figma.
- Pelajari dan ubah sendiri beberapa bagian HTML/CSS/JavaScript agar memahami kode dan memenuhi ketentuan tugas bahwa kode tidak dibuat 100% oleh AI.
- Footer sudah memuat NIM dan nama berdasarkan informasi yang tersedia.
- Google Fonts memerlukan koneksi internet; jika offline, website memakai font cadangan.
